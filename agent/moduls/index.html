    Mòduls de Seguretat

    El Diag Agent integra múltiples eines de seguretat de codi obert en un únic tauler de control unificat.

    Scanner de Vulnerabilitats (Trivy)

    Descripció

    Trivy és un escàner de vulnerabilitats complet per a contenidors, sistemes de fitxers i repositoris git.

    Configuració al Diag Agent

    def collect_trivy(limit=200):
    """
    Analitza el sistema de fitxers (rootfs) per detectar CVEs.
    Optimització: Omit directoris temporals per reduir temps.
    """
    cmd = "trivy fs / --skip-dirs /tmp --skip-dirs /var/cache -f json"
    result = subprocess.run(cmd, shell=True, capture_output=True, timeout=300)
    ...

    Funcionalitats

    Característica Descripció
    Escaneig rootfs Analitza tot el sistema de fitxers
    Filtrat per severitat CRITICAL, HIGH, MEDIUM, LOW
    Base de dades CVE actualitzada contínuament
    Optimització Skip de /tmp, /var/cache
    Límit de resultats Configurable (per defecte 200)

    Sortida

    {
  "Results": [
    {
      "Target": "apt",
      "Vulnerabilities": [
        {
          "VulnerabilityID": "CVE-2023-XXXX",
          "PkgName": "openssl",
          "Severity": "HIGH",
          "Title": "Buffer overflow in...",
          "Description": "..."
        }
      ]
    }
  ]
}

    Auditoria de Xarxa (Nmap)

    Descripció

    Nmap és l'escàner de xarxa més utilitzat, integrat amb validació d'arguments per seguretat.

    Classificació de Ports

    class NmapParser:
    DANGEROUS_PORTS = {
        21: "FTP - Unencrypted file transfer protocol",
        23: "Telnet - Unencrypted remote access (use SSH)",
        25: "SMTP - Mail server (check auth)",
        69: "TFTP - Trivial FTP (no auth)",
        110: "POP3 - Unencrypted mail",
        135: "MSRPC - Windows RPC",
        139: "NetBIOS - Windows shares",
        445: "SMB - Windows/Samba shares",
        512: "rexec - Remote exec",
        513: "rlogin - Remote login",
        514: "RSH - Remote shell",
        1433: "MSSQL - Database",
        1521: "Oracle - Database",
        3306: "MySQL - Database",
        3389: "RDP - Remote Desktop",
        5432: "PostgreSQL - Database",
        5900: "VNC - Remote desktop",
        6379: "Redis - Cache (no auth default)"
    }

    Arguments Segurs Permesos

    SINGLE_TOKEN_WHITELIST = {"-p-", "-Pn", "-sV", "-v", "-vv", "-A"}
T_TUNING_RE = re.compile(r"^-T[0-5]$")  # -T0 a -T5

    Seguretat

    • ❌ --script* rebutjat (per prevenir atacs d'esgotament de recursos i injeccions)
    • ❌ Metacaràcters shell rebutjats (;, &, |, etc.)
    • ✅ Només flags de la whitelist amb validació estricta via validate_nmap_extra_args()

    Exemple d'Ús

    # Via API REST
curl -X POST http://localhost:8080/api/nmap_scan \
  -H "Content-Type: application/json" \
  -d '{"target": "192.168.1.1", "extra_args": "-sV -T4"}'

    Intel·ligència de Menaces (Shodan)

    Descripció

    Integració amb l'API de Shodan per obtenir informació ràpida i passiva sobre IPs públiques. El Diag Agent detecta automàticament la clau d'API al fitxer .env.

    Implementació

    def scan(self) -> Dict:
    api = shodan.Shodan(api_key)
    host = api.host(ip)
    results["ports"] = host.get("ports", [])
    results["org"] = host.get("org", "n/a")
    results["os"] = host.get("os", "n/a")
    results["vulns"] = list(host.get("vulns", []))

    Dades Recollides

    Camp Descripció
    Vulnerabilitats Llista de CVEs detectats per Shodan
    Ports Oberts Ports visibles des d'internet
    Organització ISP o empresa propietària de la IP
    Sistema Operatiu SO detectat passivament
    Tags Etiquetes de Shodan (e.g., "cloud", "vpn")

    Auditoria SSH (SSH-Audit)

    Descripció

    Mòdul específic que analitza la configuració del servei SSH, detectant configuracions insegures.

    Patrons de Detecció

    class SSHAuditParser:
    FAIL_PATTERNS = [
        r'\(fail\)',
        r'weak\s+\(',
        r'broken',
        r'vulnerable',
        r'deprecated',
        r'SHA-?1',
        r'MD5',
        r'3DES',
        r'RC4',
        r'CBC mode'
    ]

    SECURE_PATTERNS = [
        r'ECDH',
        r'ed25519',
        r'chacha20',
        r'gcm@openssh',
        r'umac-128'
    ]

    Classificació d'Algoritmes

    Nivell Descripció Exemples
    🟢 Secure Recomanats Ed25519, ChaCha20, AES-GCM
    🟡 Attention Acceptables però millorables ECDSA, AES-CTR
    🔴 Fail Insegurs, eliminar 3DES, MD5, SHA1, RC4

    Report Generat

    @dataclass
class SSHAuditReport:
    banner: str = ""
    software: str = ""
    protocol_version: str = ""
    kex_secure: List[SSHAlgorithm] = field(default_factory=list)
    kex_weak: List[SSHAlgorithm] = field(default_factory=list)
    hostkey_secure: List[SSHAlgorithm] = field(default_factory=list)
    hostkey_weak: List[SSHAlgorithm] = field(default_factory=list)
    enc_secure: List[SSHAlgorithm] = field(default_factory=list)
    enc_weak: List[SSHAlgorithm] = field(default_factory=list)
    mac_secure: List[SSHAlgorithm] = field(default_factory=list)
    mac_weak: List[SSHAlgorithm] = field(default_factory=list)
    fingerprints: Dict[str, str] = field(default_factory=dict)
    recommendations: List[str] = field(default_factory=list)
    critical_issues: List[str] = field(default_factory=list)
    hardening_actions: List[str] = field(default_factory=list)

    Recomanacions de Hardening

    L'eina genera automàticament recomanacions com:

    ✅ Disable weak algorithms in /etc/ssh/sshd_config
✅ Use Ed25519 keys instead of RSA
✅ Set KexAlgorithms curve25519-sha256@libssh.org
✅ Set Ciphers chacha20-poly1305@openssh.com,aes256-gcm@openssh.com
✅ Set MACs hmac-sha2-512-etm@openssh.com

    Reconeixement OSINT (theHarvester)

    Descripció

    Mòdul de reconeixement passiu que utilitza theHarvester i Certificate Transparency Logs (crt.sh) per trobar actius exposats d'un domini.

    Flux de Treball

    1. theHarvester: Cerca en motors com Bing, DuckDuckGo, Yahoo, etc.
    2. crt.sh: Extracció de subdominis a partir de certificats SSL/TLS.
    3. Model de Validació Professional: Verifica si els hostnames trobats resolen via DNS o responen a HTTP.
    4. Highlights: Detecció automàtica de panells d'administració (Proxmox, MySQL, Grafana, etc.).

    Mètriques de Validació

    • 🔵 WEB: El servei respon a peticions HTTP/HTTPS.
    • 🟢 DNS: El hostname resol correctament via DNS.
    • 🔴 FAIL: El hostname no resol (infraestructura fantasma o antiga).

    Unified Discovery Scanner

    Descripció

    El Unified Discovery Scanner és una eina d'orquestració que combina múltiples vectors de reconeixement en una única operació atòmica sobre un domini objectiu.

    Característiques Principals

    1. DNS Recon & Subdomains

    Utilitza Subfinder i consultes DNS directes per enumerar subdominis i registres (A, MX, NS, TXT). Inclou una prova de Zone Transfer (AXFR) automàtica.

    2. SSL Analysis

    Analitza la validesa del certificat, l'emissor i calcula els dies restants fins a l'expiració, permetent preveure fallades de servei per certificats caducats.

    3. Directory Bruteforce (Anti-Redirect)

    Implementa una tecnologia de correcció d'heurística per a redireccions malformades. Si el servidor respon amb una redirecció sense barra (e.g., site.comadmin), l'agent ho detecta i corregeix la URL automàticament per fer-la accessible.

    4. Shodan Context

    Afegeix context d'infraestructura (IP, Ports, CVEs) a la mateixa vista de resultats.

    Interfície Unificada

    La interfície permet seleccionar selectivament quins mòduls executar per optimitzar el temps i l'operativa.

    AI Agents

    El Diag Agent integra tres mòduls d'intel·ligència artificial i agents distribuïts.

    Audit Manager (audit_manager.py - 625 línies)

    Mòdul central d'auditoria que combina múltiples fonts d'informació.

    Component Descripció
    Local Vulns Escaneig amb Trivy
    Zero-Days Cerca via API z.ai
    Recent CVEs Consulta a NVD (últims 30 dies)
    AI Analysis Anàlisi intel·ligent amb z.ai
    Risk Score Puntuació de risc 0-100

    Full Scan inclou: - Logs del sistema - Configuracions de seguretat - Filesystem - Xarxa i ports - Processos - Aplicacions web - Bases de dades

    from audit_manager import AuditManager

manager = AuditManager(zai_api_key="...")
result = manager.run_full_audit(target="192.168.1.100")
# result.risk_score, result.ai_analysis, result.zero_days

    Autonomous Agent (autonomous_agent.py - 148 línies)

    Agent autònom que executa comandes de forma segura, planificant accions amb AI.

    Característiques: - Comandes permeses: ls, find, cat, grep, nmap, nikto, netstat, ss, curl, dig... - Patrons prohibits: rm, dd, mkfs, chmod 777, shred - Límit d'accions: Màxim 20 accions per escaneig

    from autonomous_agent import AutonomousAgent, quick_web_scan

agent = AutonomousAgent(zai_api_key="...")
result = quick_web_scan(agent, target="example.com")
# result["final_report"], result["all_actions"]

    Beta

    L'Agent Autònom pot executar comandes al sistema. Utilitza'l amb precaució.

    Target OS Scan (Multi-Platform)

    El Diag Agent incorpora un escàner multi-plataforma que permet auditar diferents sistemes operatius de forma remota.

    Sistemes Suportats

    OS Icona Escanejos Disponibles
    Windows 🪟 Port Scan, SMB Enumeration, RPC Enumeration, LDAP/AD, Vulnerability Scan (MS17-010...), WinRM Check
    macOS 🍎 Port Scan, SSH Audit, Services (AFP, Bonjour, AirPlay)
    iOS/iPadOS 📱 Port Scan, Services (Sync/Debug port 62078)
    Linux 🐧 Port Scan, Services Enumeration, SSH Audit

    Característiques

    • Escaneig selectiu: Selecciona exactament quins mòduls executar per cada OS
    • Validació de host: Comprova si el target és accessible abans d'escanejar
    • Múltiples eines: Utilitza nmap, smbmap, smbclient, rpcclient, ldapsearch, ssh-audit
    • Resultats estructurats: JSON parseejat amb vulnerabilitats, ports i serveis

    Accés

    Navega a /os-scan per accedir a la interfície d'escaneig multi-OS.

    API

    # El mòdul s'importa des de os_scanner.py
from os_scanner import OSScanner, SCAN_DEFINITIONS

scanner = OSScanner()
result = scanner.scan(
    target="192.168.1.100",
    os_type="windows",  # windows, macos, ios, linux
    scan_options=["windows_ports", "windows_smb", "windows_vulns"]
)

    Exemple: Escaneig Windows

    # Des de línia de comandes
python3 os_scanner.py 192.168.1.100 windows

    Requereix permís

    Alguns escanejos (especialment SMB/RPC a Windows) necessiten que el host permeti connexions anònimes o requeriran credencials.

    Integració Telegram

    El Diag Agent permet enviar informes PDF directament a Telegram mitjançant un bot configurat.

    Configuració

    Al fitxer .env:

    TELEGRAM_BOT_TOKEN=1234567890:AAE-abcdefghijklmnopqrstuvwxyz123456
TELEGRAM_CHAT_ID=123456789

    Funcionalitat

    • Pentest Reports: Envia informes de vulnerabilitats web
    • Shodan Intel: Envia informes d'intel·ligència d'infraestructura
    • Custom Caption: Inclou target, data i resum de troballes

    API

    POST /api/pentest/telegram/<scan_id>
Body: {"chat_id": "123456789"}  # Opcional si ja està a .env

    Bones Pràctiques

    1. Executar Trivy primer per tenir una visió general
    2. Utilitzar Nmap amb -sV per detectar versions
    3. SSH-Audit per validar configuració SSH
    4. Enum4Linux només si hi ha serveis SMB
    5. Nikto/SQLMap només amb autorització explícita
